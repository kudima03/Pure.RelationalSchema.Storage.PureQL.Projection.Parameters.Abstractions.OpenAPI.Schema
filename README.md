## Overview

This package will provide an AOT-compatible ASP.NET Core `IOpenApiDocumentTransformer` that replaces the generated schemas of the interfaces of [`Pure.RelationalSchema.Storage.PureQL.Projection.Parameters.Abstractions`](https://github.com/kudima03/Pure.RelationalSchema.Storage.PureQL.Projection.Parameters.Abstractions), `IParameterType`, `IParameter` and `IListParameter`, with schemas matching their JSON.
